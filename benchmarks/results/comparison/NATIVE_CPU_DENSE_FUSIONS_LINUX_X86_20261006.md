This report records the 6 October 2026 comparison generated by the executable
`simulator_workload_corpus` runner. It measures exact 22-qubit complex128
statevector execution through each framework's public user-facing path. The raw

## What changed

Two inference-only CPU patterns now avoid redundant full-state memory passes:

- Truncated QFT compiles each static Hadamard plus its following controlled-phase
  graph into one native C++/OpenMP pass. The 22-qubit plan falls from 54 compiled
  statevector applications to 24.
- A static CX chain followed by a disjoint RZZ and SWAP compiles into one compact
  linear-permutation-and-phase pass. The two-layer hardware-efficient workload
  replaces six full-state applications with two.
- Consecutive general SWAP gates also share one materialized tensor permutation.

The fast paths fail closed. Trainable state or gate tensors keep the existing
autograd implementation, and each optimization has an environment rollback.

## What is measured and why it matters

The hardware-efficient case contains two layers of RX/RY/RZ gates, a full
nearest-neighbour CX chain, one nonlocal RZZ, and one SWAP. It represents the
mixed rotation, entanglement, phase, and routing traffic common in variational
circuits. Truncated QFT contains bounded-range controlled phases and final wire
reversal, exposing repeated phase-graph and permutation traffic. The other four
workloads guard against improving those two shapes by regressing Clifford,
local, dense-nonlocal, or routing-heavy execution.

## FlagQuantum example

```python
import torch
import flagquantum as fq

circuit = fq.Circuit(22, dtype=torch.complex128)
for wire in range(22):
    circuit.rx(wire, 0.11).ry(wire, -0.07).rz(wire, 0.03)
for wire in range(21):
    circuit.cx(wire, wire + 1)
circuit.rzz(0, 21, 0.0275).swap(1, 20)

state = circuit.state()
print(state.shape)
```

No user option is required. The compiler selects a native path only when its
static, inference-only preconditions are proved.

## Environment

- Python: 3.12.13

- FlagQuantum: 0.2.0 from this PR checkout

- PennyLane: 0.45.1; PennyLane Lightning: 0.45.0

## Reproduce

```bash
taskset -c 0-31 flagquantum-benchmark run simulator_workload_corpus \
  --workloads hardware_efficient_statevector truncated_qft_statevector \
    random_clifford_statevector local_brickwork_statevector \
    dense_nonlocal_statevector swap_routing_statevector \
  --n-wires 22 \
  --engines flagquantum_native qiskit_aer pennylane_lightning_qubit \
  --threads 32 --warmup 2 --iterations 9 --calls-per-sample 1 \
  --json-output native_cpu_dense_fusions_linux_x86_20261006.json
```
