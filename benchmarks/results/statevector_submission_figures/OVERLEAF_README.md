# Overleaf instructions

Upload every file in this directory to one Overleaf project and select
`main.tex` as the main document. The draft uses standard TeX Live packages and
compiles without a bibliography.

Before submission:

1. Replace the `article` document class and `geometry` package with the
   official target-year MLSys style.
2. Keep the four figure PDFs beside `main.tex`, or update their paths.
3. Replace every red `TODO` after the corresponding experiment or verified
   related-work review is complete.
4. Switch from anonymous to author metadata only when permitted by the
   submission process.
5. Do not remove the development-evidence limitations unless the unified rerun
   has actually completed.

Files:

- `main.tex`: complete paper skeleton with current results;
- `PAPER_PLAN.md`: readiness assessment and experiment roadmap;
- `CAPTIONS.md`: standalone English captions;
- `SOURCES.md`: exact JSON provenance for every plotted result;
- `fig1`–`fig4`: PDF/SVG/PNG submission figures.
