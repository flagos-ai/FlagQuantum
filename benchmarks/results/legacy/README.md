# Legacy benchmark holdings

This directory contains historical experiment families retained for published
reports, paper reproduction, or migration review. Its contents are not a fifth
evidence class and must not be used as release evidence by directory placement.

Do not add new result families here. New results must use one of the canonical
classifications in the [results index](../README.md): `local/`, `comparison/`,
`smoke/`, or `scalability/`. Bulky raw and superseded material should be stored
outside the source repository according to the
[repository governance policy](../../../docs/development/REPOSITORY_GOVERNANCE.md).

Each retained family should eventually be reviewed for one of three outcomes:

1. promote the minimal current evidence into a canonical class;
2. archive the raw payload externally and retain a compact manifest;
3. remove it after all published references are superseded.
