# Capacity Model Fixtures

Files here are plans or estimated capacity/schema fixtures. They are never
scanned as promoted scalability results and may not populate runtime-measured
fields.

The Phase 4 eight-rank statevector model is CPU-labelled and has no automatic
runtime provenance or raw-log signature. It remains useful for fail-closed
contract tests, but it is not production evidence unless a new hardware run
generates a signed `measured_production_run` artifact.
