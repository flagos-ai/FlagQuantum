# Support

For participation and review expectations, read the
[code of conduct](CODE_OF_CONDUCT.md) and
[contribution guide](CONTRIBUTING.md).

## Questions, bugs and feature requests

Search the [issue tracker](https://github.com/flagos-ai/FlagQuantum/issues) for an
existing report or discussion of the behavior. Add relevant evidence to that
report, or open a new issue when the topic has no existing report.

Include the affected version or commit, the execution target, a minimal
reproduction and the expected and observed results. For installation problems,
include the Python version, operating system and installation command. The
[contribution guide](CONTRIBUTING.md#reporting-bugs--suggesting-improvements)
describes the existing issue and change workflow.

## Private reports and maintainer contact

Report suspected security vulnerabilities through the
[security policy](SECURITY.md#reporting-a-vulnerability). It gives the private
channel and the information that helps assess a report. Conduct concerns follow
the [conduct policy](CODE_OF_CONDUCT.md#enforcement).

The package's recorded maintainer contact is
[flagquantum@gmail.com](mailto:flagquantum@gmail.com). The
[governance document](GOVERNANCE.md) describes current decision-making and
maintainer responsibilities. Response expectations for security reports are
stated in the [security policy](SECURITY.md#what-to-expect).
