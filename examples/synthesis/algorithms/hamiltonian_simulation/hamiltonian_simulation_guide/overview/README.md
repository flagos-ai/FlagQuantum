# Native Hamiltonian Notebook

Open the [Notebook](walkthrough.ipynb) and run all cells from the repository root.
Run its computation without Jupyter:

```sh
python -m examples.synthesis.algorithms.hamiltonian_simulation.hamiltonian_simulation_guide.overview.main
```

See [workflow acceptance](WORKFLOW.md) and [source provenance](provenance.json).

Plotting requires optional Matplotlib. Use `MPLBACKEND=Agg` for headless execution.
The complete local CPU sweep takes approximately a minute, depending on the host.
