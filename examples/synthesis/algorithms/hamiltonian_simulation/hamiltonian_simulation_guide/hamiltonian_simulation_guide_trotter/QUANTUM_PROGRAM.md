# Ordered Hamiltonian quantum program

The native qfunc preserves the original two-bit Hamiltonian, time one,
first-order product formula and ten repetitions. Observable indices bind to
logical target elements with index zero least significant. `build_program(time)`
also allows explicit finite-real specialization for other times.

An independent Circuit forms each Pauli exponential from a dense matrix and
compares full complex amplitudes. The related Hamiltonian Simulation Notebook
also covers other evolution methods and analysis; that complete workflow is
not counted as delivered by this quantum-program migration.
