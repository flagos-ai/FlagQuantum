# Discrete logarithm: complete Notebook workflow

Run from the repository root:

```sh
python -m examples.synthesis.algorithms.number_theory_and_cryptography.discrete_log.overview.main
```

Open `walkthrough.ipynb` for both original scenarios, actual sampled observations,
classical recovery, resources and the two source illustrations. No hosted service
or runtime package installation is required. NumPy and Matplotlib support plotting.

The parent directory retains the frozen quantum counterpart. This workflow adds
the complete original Notebook; see [WORKFLOW.md](WORKFLOW.md) for the cell mapping
and semantic qualifications, and [provenance.json](provenance.json) for source pins.
