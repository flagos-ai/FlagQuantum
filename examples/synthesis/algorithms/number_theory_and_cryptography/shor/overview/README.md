# Shor: complete Notebook workflow

```sh
python -m examples.synthesis.algorithms.number_theory_and_cryptography.shor.overview.main
```

Open `walkthrough.ipynb` for the classical warm-up, continued fractions, actual
2048-shot phases, recovered period and factors, and measured histogram. The quantum
problem preserves modulus21/base11, ten phase bits and five residue bits. NumPy
and Matplotlib are optional Notebook dependencies; no hosted service is needed.

The parent directory retains the frozen quantum counterpart. See
[WORKFLOW.md](WORKFLOW.md) for all seventeen source cells, explicit mathematical
corrections and verification, and [provenance.json](provenance.json) for source pins.
