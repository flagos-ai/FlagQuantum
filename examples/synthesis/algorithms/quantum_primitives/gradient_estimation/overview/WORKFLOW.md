# Native gradient workflow

Classification: `single_device_fast_path`. Preserve three-bit signed coordinate
words, the three-bit signed fractional auxiliary and every original polynomial,
sweep value and strict success threshold. Fixed callback applications become
visible native polynomial quantum helpers. Classical coefficients are bound
before synthesis; no generic QCallable support is claimed. Two-dimensional
coordinates use named x/y ports rather than a QArray of QNum.

The physical auxiliary experiment prepares the all-one basis state by an
amplitude vector and Fourier-transforms it. A separate Fourier within/apply
region implements its exact modular addition. The outer region then reverses
preparation, and `drop` ends the verified clean lifetime. No fractional bit
views or direct fractional += implementation is claimed. An independent
six-qubit Circuit applies a controlled modular-add permutation and verifies
every complex amplitude, including the auxiliary. Other independent Circuits
use mathematical phase diagonals and dense Fourier matrices. All comparisons
include absolute global phase and hidden compiler work.

Phase tables sort signed coordinates, round measured turns to five decimals,
unwrap with period one and subtract the x=0 entry. This plotting convention
is separate from the absolute full-state check. Actual seeded sampling uses
named numeric probabilities; majority, signed gradient decoding and joint
success are computed from actual counts. Default tolerance is m/16 and the
m-sweep retains the source override 0.2. Every source parameter is retained.

The ten source plots include secondary physical-coordinate axes, phase tables,
measurement histograms and both complete success-rate sweeps. Source helper
globals become an immutable Model, and source helper hashes remain provenance
outside executable user code. Resource reports describe synthesized instructions
before Runtime basis conversion. No source importer, compiler/API/dependency
change, hardware run, speedup, scalability or optimality claim is made.
