Complete retained 24-bit 5-layer quantum program. Two nonzero parameter vectors and both width/depth objectives; raw full-state comparison with independent factored classical costs and Circuit parities. Complete Notebook optimizer workflow remains pending.

Parameters retain interleaved gamma/beta order. Native static loops replace repeat/apply_to_all. Source coefficients, widths and layers are unchanged. No source importer in user examples. Each reference factor enumerates at most six logical bits, with independent Walsh spin-parity Circuit construction; no Compiler algorithms reused. Retain source rounded edge weights, all three flow commodities, and cubic congestion equivalent to a capacity-two threshold, including the all-three-selected state. It is not reduced to a purely quadratic cost.

Run the commands in [README](README.md) for the complete native program and
independent Circuit comparison. Twenty-four-bit examples require a local
complex128 statevector; they print resources and norm instead of constructing
an enormous Python probability dictionary. No width, layer, coefficient or
parameter reduction is used to claim coverage.

Acceptance checks absolute complex128 amplitudes without phase alignment,
logical bit order and zero workspace. The reference only enumerates small
classical factor tables and applies bounded one/two-qubit Circuit operations;
it does not allocate a dense matrix over the entire problem. Static IR
instruction counts and scheduling are reported separately from the frozen
source baseline and do not certify hardware efficiency or optimality.
