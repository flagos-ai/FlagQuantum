# Mock-QAE cost input

The 64-entry `costs.json` preserves the numeric contents of the original
NumPy file for the separate one-phase-bit mock-QAE example.
[Provenance](../provenance.json) pins the upstream byte identity and the
native JSON content. The workflow regenerates the thermal matrices and
solutions. The source repository notice is preserved in the
[third-party license](../../../../../CLASSIQ_LICENSE.txt).
