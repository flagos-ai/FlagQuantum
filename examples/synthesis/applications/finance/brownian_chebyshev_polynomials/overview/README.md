# Brownian series with Chebyshev recurrences

Run the complete local example from the repository root.

```sh
python -m examples.synthesis.applications.finance.brownian_chebyshev_polynomials.overview.main
```

[The walkthrough](walkthrough.ipynb) completes the original 14 stages.
Gaussian masses are regenerated by integrating the standard normal over
the original bins. The one-bit distribution has exactly equal branch
weights, so it satisfies the retained native Wiener qfunc's preparation
contract.

Both standalone arithmetic demonstrations use exact fixed-point
encodings and reversible output XOR. The Chebyshev demonstration uses
the source's (x) multiplier after the initial (2x) term. The final
four-term Wiener series uses the source's cosine approximation as its
recurrence multiplier and retains the signed 8-fractional-bit price
format. The full execution reports the exact named time and price
marginal and is checked against an independent reversible Circuit over
all retained branch amplitudes.

The measured width stays inside the source limit of 139 physical
qubits. The resource report retains the actual compiler workspace and
the discarded coefficients' effect on the marginal.
