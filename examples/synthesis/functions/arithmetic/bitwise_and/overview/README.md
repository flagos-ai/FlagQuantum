# Bitwise AND workflow

Run `python -m examples.synthesis.functions.arithmetic.bitwise_and.overview.main`
for both complete Notebook programs and local seeded samples. The register form
computes 4 & 5 = 4; the mask form computes 5 & 3 = 1. The workflow uses native
qfuncs and contains no gate sequences or wire-number manipulation.

The individual native programs and their independent Circuit references are
linked here:

- [two-register AND](../bitwise_and_2vars_example/README.md)
- [literal-mask AND](../bitwise_and_integer_example/README.md)
