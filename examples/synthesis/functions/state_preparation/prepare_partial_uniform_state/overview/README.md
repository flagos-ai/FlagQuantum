# Native Partial Uniform Notebook

Open the [Notebook](walkthrough.ipynb) and run every cell from the repository root.
Run the same computation without Jupyter:

```sh
python -m examples.synthesis.functions.state_preparation.prepare_partial_uniform_state.overview.main
```

See [workflow acceptance](WORKFLOW.md) and [source provenance](provenance.json).

Plotting requires the optional `matplotlib` package. The Python command opens
both plots on interactive backends; use `MPLBACKEND=Agg` on headless systems.
