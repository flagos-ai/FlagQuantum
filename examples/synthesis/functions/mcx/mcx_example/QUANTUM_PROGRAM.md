# Retained native control program

Keep the original width, allocation order and all-ones activation condition.
No source importer is used. Control arrays mean conjunction of every bit,
not an unsigned nonzero test. No hidden measurement or reset is inserted.
The full state, absolute phase and zero workspace are independently checked.
The separate 50-control tutorial now has its own checked exact product-MPS
acceptance; these smaller examples continue to use exact statevectors.
