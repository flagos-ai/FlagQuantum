# Discrete quantum walks

Run two 50-step walks on a 128-site circle, a four-step walk on the
four-dimensional hypercube, and a constrained circuit benchmark for one step
on a 1,024-site circle.

```bash
python -m examples.synthesis.tutorials.advanced_tutorials.discrete_quantum_walk.overview.main
```

Open [the Notebook](walkthrough.ipynb) for the signed-position distributions,
the opposite-corner probability, and the CX counts for widths 12 through 20.
The three native simulations each draw 10,000 finite position samples.
