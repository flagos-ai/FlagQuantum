# python program

Prepare and compose x*x+y using native high-level qfunc.

## Run

```sh
python -m examples.synthesis.tutorials.composition.python_program.main
python -m examples.synthesis.tutorials.composition.python_program.comparisons.circuit
```

The independent Circuit comparison checks complete complex amplitudes,
absolute phase and hidden workspace. It uses the native program directly.
Original importer comparisons are retained separately as test evidence.
