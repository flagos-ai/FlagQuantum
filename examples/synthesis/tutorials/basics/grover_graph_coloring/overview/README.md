# Native graph coloring Notebook

Run the complete [Notebook](walkthrough.ipynb) from the repository root, or use:

```sh
python -m examples.synthesis.tutorials.basics.grover_graph_coloring.overview.main
```

Plotting requires optional Matplotlib. Set `MPLBACKEND=Agg` for headless execution.
