# boolean factors

A Boolean product phase in native qfunc, Qmod and an independent Circuit.

## Run

```sh
python -m examples.synthesis.tutorials.arithmetic.boolean_factors.main
python -m examples.synthesis.tutorials.arithmetic.boolean_factors.comparisons.circuit
```

The independent Circuit comparison checks complete complex amplitudes,
absolute phase and hidden workspace. It uses the native program directly.
Original importer comparisons are retained separately as test evidence.
