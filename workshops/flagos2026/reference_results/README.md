# A recorded hardware result

`quafu_bell_replay.json` contains counts from a real 1024-shot Bell experiment run on September 9, 2026.
It is an excerpt of the repository's [execution record](../../../artifacts/development/quafu_explicit_mapping_dongling_20260909.json).
See that record for the physical qubits, calibration, and full task details.

Notebook 06 uses this file so you can learn to compare results even when hardware is unavailable.
Its source is labeled `historical_replay`; it is not a task submitted by the current participant.
Keep this label when presenting or sharing the result.

The counts describe measurement outcomes in the Z basis. They are not a measurement of state fidelity or, by themselves, proof of entanglement.
