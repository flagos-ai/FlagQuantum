# TeX runtime provenance

Retrieved 2026-10-21 from https://github.com/projekter/yquant (yquant 0.9.1)
and https://github.com/HarisIqbal88/PlotNeuralNet (master snapshot).
Archive SHA-256 values are preserved in `licenses/`. Original upstream runtime
files from yquant are unmodified. PlotNeuralNet's three MIT-licensed styles have
only line endings and trailing whitespace normalized to repository conventions;
their TeX commands and geometry are unchanged. Original license texts are
distributed alongside this bundle. The LPPL license is retained verbatim,
including its original whitespace, and checked by a resource integrity test.

`flaghybrid.sty` is the MIT-licensed FlagHybridTeX composition layer. All new
Python integration code is Apache-2.0. yquant is LPPL-1.3c; PlotNeuralNet is MIT.
This optional rendering dependency is isolated in the drawer, adds no executable
simulator contract and can be replaced through the source/rendered-bytes boundary.
The API proposal documents dependency ownership, replacement and exit criteria.
