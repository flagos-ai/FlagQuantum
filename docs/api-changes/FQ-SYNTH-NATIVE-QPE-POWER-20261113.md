# Static power callbacks for experimental native QPE

The complete native Notebook migration is the standing user authorization for
this additive, unreleased `flagquantum.synth` admission. It changes no Stable
Core export or serialized program schema. Compiler owns capture and lowering;
Integration owns this successor contract and its enforcement. The original
matrix and ordinary-callback contracts remain historical admission records.

The matrix-QPE Notebook requires a different product-formula approximation for
each power. Repeating one approximate unitary changes its algorithm. Keep
`qpe(lambda: operation(...), counter)` unchanged. Add
`qpe(lambda power: operation(..., power, ...), counter)`: the compiler binds
`power = 2**bit` for each of at most eight bits, captures one pure call and
controls it once. Matrix callbacks must not be powered twice. No host callback
execution, quantum-dependent indexing or new IR effect is introduced.

Reuse mutable helper borrowing, finite classical bindings, pure effect and
counter-disjointness checks, controlled identity/global phase, inverse Fourier
and the 4096 effect ceiling. Reject defaults, keyword/variadic parameters,
captured-name shadowing, allocation, ownership changes, Output escape, aliases,
nonunitary effects and resource excess. Restore the lexical power binding even
when capture fails. All existing zero-argument workflows remain valid.

Acceptance compares full complex state vectors against independently assembled
controlled matrices, including absolute phase and retained private environments.
Check every power, a nonlinear per-power family, scalar phases, primitive and
helper callbacks, lexical restoration, matrix no-double-power behavior and
refusals. The original matrix Notebook additionally retains its 4x4 matrix,
seed-8 amplitudes, seven signed fractional bits, exact evolution and order-two
Suzuki repetitions 2,3,5,7,11,16,23. Both 10000-shot workflows and plots are
required before full Notebook coverage credit. This contract alone earns none.
Release and remote execution are not authorized by this admission.
