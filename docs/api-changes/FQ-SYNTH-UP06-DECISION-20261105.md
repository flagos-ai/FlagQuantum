# UP-06 bounded predicate decisions and clean factor scheduling

This private adapter profile replaces a refusal path, without changing public
exports, owned opcodes or physical templates. The established eight-input phase
enumeration path remains first and unchanged. Its budget refusal may select a
separately checked decision decomposition with at most twelve physical inputs,
262144 evaluator steps, 4096 decision nodes and 128 disjoint accepting cubes.
Classical evaluation interprets only the closed admitted integer/Boolean AST;
no user host callable or foreign SDK executes. Leaf enumeration is bounded at
eight input bits. Larger domains or exhausted node/path/evaluation bounds refuse.

A reduced ordered decision graph removes equal branches and shares identical
subproblems. Its accepting paths partition the marked subspace, preserving an
arbitrary finite phase angle exactly once per marked basis word. Negative
differences retain mathematical sign; unsigned modulo and bitwise operations
keep the existing checked domain. Numeric input order is explicit and stable.

Each accepting cube is divided into groups of at most six signed bit literals.
Groups use the existing Boolean compute representation and candidate selection;
the phase uses existing owned indexed controls. Each cube's group flags are
uncomputed and released before the next cube. Compiler's existing clean-tail
scheduler owns actual reuse and its clean MCX kernel owns physical realization.
This is bounded sequential cleanup/recomputation, not a new canonical IR or a
claim of globally optimal scheduling. Degree, phase-width, owned-effect and
final resource caps remain independent and unchanged. An arbitrary phase
polynomial still has to fit the existing final indexed-control width.
