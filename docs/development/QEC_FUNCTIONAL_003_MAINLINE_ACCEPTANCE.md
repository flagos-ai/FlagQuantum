## Runnable public example

With an installed distribution, or `PYTHONPATH=.` from the source checkout:

```bash
python examples/qec/circuit_noise_dem.py
```

Expected stdout:

```text
Physical qubits: 49
Detectors: 72
Logical observables: 1
Sample shapes: (4, 72) (4, 1)
```

This constructs and samples a declared detector model using the supported
single-qubit bit-flip channel. It does not execute a 49-qubit dense statevector,
validate decoder quality, or demonstrate correlated circuit-noise support.
