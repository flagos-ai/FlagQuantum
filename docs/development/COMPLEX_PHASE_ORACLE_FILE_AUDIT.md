# Complex phase oracle source audit

The reference is Qualtran v0.7.0 at
`bcb17bb25360ed68ce3bc084645db3e929799389`. The audit hashes the original
`complex_phase_oracle.py` (`6abd4c2811b54184eb1ba33e06c1d11d919c852c`)
and `complex_phase_oracle_test.py` (`ab6dc2af6345641052518c37f2206b44dbd8efc3`).

`ComplexPhaseOracle.make_on` binds an existing coherent encoder for use
with `circuit.append(op)`. The encoder's control and selection ports pass
through in declaration order. Its target groups form an unsigned big-endian
word on caller-owned clean wires. The oracle computes the sign and fractional
magnitude of `-2*atan(x)/π`, applies the signed phase, erases the angle by
repeating the XOR lookup, and reverses the captured encoder. The encoder's
adjoint is generated by the existing circuit inverse. Internal lookup scratch
and classical slots can be reused between the compute and erase calls.

The source calls its opaque ArcTan arithmetic gate before and after the phase
ladder. The native bounded realization uses the existing unary QROM built
from the exact fixed-point words. The audit compares both lookup streams with
independently constructed source QROMs, including operands, measurement
feedback and per-wire order. For encoded widths 2, 3 and 5, the And channel
certificate proves each lookup's complete output and clean scratch for every
outcome on all input integers. The signed phase visits the same fractional
digits and applies the same alternating polarities and angles as the locked
Cirq layer. The native zero-control primitive uses two X wrappers. The
positive and negative phase branches need no additional work.

All 12 original width/precision cases have full native complex-state checks
including the zero-work support and inverse recovery. Two-bit encodings cover
all actual measurement histories. For wider cases the native execution uses
two sampled histories per forward case, with separate exact channel
certificates on the representative lookup widths above. A coherent
controlled-copy fixture verifies multiple encoder target registers, nontrivial
encoder phase cancellation, and work cleanup. The original controlled
`ExampleSelect` is used only for its diagram and signature, as its
decomposition omits the `control` parameter. The unchanged reference suite
passes all 13 cases.
