## Ownership and source payload loss

Ecosystem's `capture_linear_combination_context` receives an explicit SDK
LinearCombination object and immediate native PREPARE/SELECT conversion owners.
It captures the real source roles before discarding the external objects.
The resulting frozen context contains a native Signature, resolved maximum
child ancilla/resource widths, selection/junk widths, precision/control state
and two complete exact native Program pairs. Physical Programs and external
objects returned as child pairs are rejected at this boundary.

Formats' `linear_combination_factories` binds those contexts to explicitly
assigned definition identities. The original shallow producer drops private
blocks, coefficients and optional oracles. A surviving signature, precision
and control flag cannot identify an operator. Unknown bindings fail; known
bindings validate the surviving fields and signature before body composition.
An adversarial witness has identical shallow arguments and register descriptors
but different PREPARE semantics. Both explicit bindings retain their original
recursive source calls and full, distinct complex operators.

The SDK's wire projection drops symbol assumptions. Ecosystem first takes the
source's already-resolved maximum widths, then projects them through existing
native codecs. It retains the actual converted source Signature rather than
recomputing maxima after assumption loss. Unused zero, negative and symbolic
precision remains accepted with supplied oracles; symbolic physical widths
retain source-compatible declarations and physical refusal. No wire schema,
Stable Core entrance or zero-port execution behavior changes.

## Exact calls, controls and replacement

PREPARE, child-system packing, SELECT, exact unpreparation, unpacking and joins.
Logical selection/junk and child words remain caller-owned. Child-private work
retains its source lifetime and must return clean.

Positive-controlled source roots receive their actual source-selected SELECT
owner. Negative and grouped controls reuse ControlledViaAnd and an explicitly
converted positive native context. Generic adjoints rebuild the exact inverse
root under the same predicate and measurement-erasure owners, including outer
predicate cleanup; no measurement instruction is reversed. One-, two- and
three-bit cases exhaust every small raw history and verify complex amplitudes,
branch weights and zero work. Constructor imports also preserve byte-for-byte
primitive streams and allocation/release wire events from the accepted direct
root. Source-free ordinary and grouped-control resolve/bind/append are tested.

Unknown control/adjoint children delegate to explicitly supplied existing
owners. The shared fixed X/Y/Z/H positive-control dependency now calls the
registered CNOT/CY/CZ/CH definitions with their exact source operand names:
`ctrl/target` or `q1/q2`. Its enclosing through-port contract and primitive
semantics remain intact. All four delegation witnesses compare recursive
source calls and full complex operators.
