# Binary field source decomposition boundaries

This G2 implementation contract follows the already authorized full-file
migration and faithful-source closure rule. No Stable Core export, opcode,
serialized vocabulary, metadata validator or numerical arithmetic admission is
changed. Original Qualtran v0.7.0 files remain unchanged.

Compiler owns literal decomposition graphs. Square retains the original M/R
matrix-power schedule and the original ignored physical inverse flag. Existing
mathematical Frobenius and exact inverse owners keep their behavior. Both word
profiles share the same coefficient-array/word adapter and binary PLU emitter.

Register addition retains the source's loop over field degree, which is distinct
from storage width for an odd-characteristic field. Such a graph is a raw-bit
unitary and can leave the field's valid value domain. It must not be presented
as numerical nonbinary field addition. The existing mathematical binary adder
continues to reject odd-characteristic fields. Source scalar field callbacks
remain separately owned by Simulation.

Simulation owns projecting numerical field declarations to canonical quantum
IR metadata. At that existing projection boundary, nonsymbolic integral scalar
parameters are represented by their exact Python integer values. The lazy
encoding keeps the original scalar object; symbolic expressions remain exact.
Classical projection is unchanged. Explicit malformed or boolean-valued Core
field descriptors remain rejected by the unchanged Core validator; projection
does not admit a new IR parameter kind, rounding or an unresolved dimension.

Examples compose these owners for the existing catalog entry points. Concrete
integral constant values are lowered to bit patterns without numerical rounding;
symbolic constants preserve the original decomposition refusal and symbolic
resource bound. Actual source byte/codecs, primitive inventories, independent
models, numerical callback results and corrected native operations are separate
observations. Ordinary use remains circuit.append(op).

Implementation commits are separated by domain/module. Acceptance requires
actual untouched-source calls, operands and returned leases; full complex
operators and coherent spectators; zero clean work; and independently queried
source model counts. No measurements occur in these linear fixtures. Existing
source tests, notebooks and presentation evidence are reused after checking that
the selected dependency paths are unchanged. Source defects do not waive a
missing valid-source native path.
