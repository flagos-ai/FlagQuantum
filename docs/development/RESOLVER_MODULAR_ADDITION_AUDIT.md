## Original Montgomery wire loss

The original data_types serializer omits QMontgomeryUInt.modulus. The unchanged
ModAdd constructor recreates modulus-bearing signature fields from its explicit
mod argument, while its serialized register declaration contains no modulus.
The original deserializer ignores that register mismatch and reconstructs the
constructor's modulus-bearing signature. The native explicit resolver checks
that its function signature equals the declared signature and refuses this wire.
A regression records the original restored signature, actual decoded declaration
and native refusal. Direct construction without the lossy declaration matches
the existing original graph. No generic resolver guard or schema is weakened.
This remains a concrete ModAdd wire gap, so its identifier is partial.

CModAdd's explicit dtype argument and register declaration undergo the same
original dtype codec. Its restored dtype is the width-only Montgomery view and
its native constructor remains consistent with that restored wire object.
Original raw dtype metadata and restored wire metadata are distinct evidence.
