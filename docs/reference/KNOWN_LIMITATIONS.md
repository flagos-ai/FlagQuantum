# Known limitations

FlagQuantum publishes support claims per capability, not for the package as a
whole. The authoritative status and evidence requirements are defined in
[`capability-maturity.toml`](../../capability-maturity.toml) and explained in
[`CAPABILITY_MATURITY.md`](../roadmap/CAPABILITY_MATURITY.md).

| Capability | Current level | Limitation |
| --- | --- | --- |
| IR v1 | `release_certified` | Incompatible schema changes require an explicit migration. |
| Local statevector | `production_supported` | Capacity is bounded by one device; larger statevectors require the sharded runtime. |
| Sharded statevector training | `production_supported` | Multi-node release certification requires promoted, audited hardware evidence. |
| Sharded MPS training | `development_evidence` | Two independent two-node 16×A800 runs complete 131,072 sites at χ768 with 1151.84 GiB logical state in 373.80 s and 367.37 s. Peak allocation is 72.41 GiB/rank and all 16 ranks, 15 boundaries, error checks, and cleanup checks pass. The repeated artifact is sealed and records expandable CUDA allocator segments; without that policy, fragmentation causes OOM despite about 7.8 GiB reserved-but-unallocated memory. Capacity multi-step soak, sealed fault matrix, clean/signable source, and release payload remain incomplete. |
| Tensor-network training | `experimental` | A 36-qubit checkpointed and rematerialized sliced reverse completed ten consecutive rank-owned SGD steps on two nodes and 16 A800 GPUs with gradients reduced to unique optimizer owners, per-step cross-rank parameter consistency, and NCCL IB/RDMA evidence. Unit-extent canonicalization, optional cotengra path import, memory-aware full-tape selection, and staged forward execution now provide faster development evidence, but adaptive reslicing changes the contraction plan across GPU counts and is not fixed-plan strong-scaling evidence. Cotengra remains an optional dependency, compiled reverse is not the default fast path, and no release-authorized signed artifact exists. Joint memory policy also remains development-only until its reserved-memory prediction is calibrated across the declared GPU, dtype, and topology matrix. |
| Noisy simulation | `experimental` | Versioned `NoiseModel`, validated Kraus channels, and timestamped `DeviceNoiseProfile` input support exact density-matrix execution, reproducible batched statevector trajectories, and MPS trajectories with checkpoint/resume. The auditable selector evaluates density/SV/MPS candidates with memory estimates, error semantics, rejection reasons, optional exact-workload A800 timing calibration, and target-error costs from `Var(Pauli) <= 1`, a fixed-ID pilot point estimate, or a bounded-variance upper confidence limit with simultaneous-observable correction. Runtime convergence always uses observed global standard error. All-ineligible plans fail closed. The statevector path uses global-ID random streams, true `[trajectory, circuit_batch, amplitude]` blocks, Pauli and amplitude-damping fast paths, generic multi-wire Kraus execution, readout propagation, and memory-aware auto dispatch. Under initialized torch.distributed, public `fq.run` infers rank/world size and performs NCCL trajectory-statistics reduction; retained states fail closed instead of implicit gathering. Collective target-standard-error stopping is supported when the requested ceiling is divisible by world size × trajectory batch. Rank-local atomic statistics checkpoints bind circuit/model/seed/schedule identity and have 8×A800 restart evidence. Failed batches can degrade to per-trajectory retry, preserving successful statistics and explicit failure IDs; injected 8-GPU evidence completed 127/128 without a collective hang. Its 1/2/4/8×A800 fixed-workload evidence reaches 7.29× speedup and 91.1% efficiency at 8 GPUs; those measurements now have strict world-size-specific selector artifacts. Distributed calibration currently covers noisy statevector only. Noisy MPS exposes manual rank-local ownership and post-run merging, but public execution has no automatic rank inference or collective reduction, so the selector and public execution without an explicit rank fail closed for `world_size > 1`. Selector calibration and pilot-size evidence are not yet broad enough to generalize across circuit families or devices. Large channel arity remains exponentially costly. Built-ins cover bit/phase flip, depolarizing, amplitude/phase damping, reset error, thermal relaxation, coherent over-rotation, and classical readout confusion. Calibration lowering uses an explicit ASAP wire-clock approximation for gate and idle relaxation, with provenance metadata and fail-closed missing durations. Single-rank MPS execution supports target-standard-error stopping with explicit convergence status. Multi-wire MPS channels use an explicitly dense correctness fallback. Pulse overlap, crosstalk, leakage, calibration-provider adapters, distributed MPS adaptive stopping, process/GPU/NCCL fault recovery, noisy gradients, and broad hardware-derived validation remain unsupported. Scalability claims are limited to the documented A800 workload. |
| Cloud deployment | `development_evidence` | Provider behavior and credentials vary; no provider is release certified. |
| Dynamic circuits | `experimental` | Provider-neutral active-reset, conditional-flip, and qubit-reuse conformance vectors pass on the FlagQuantum trajectory runtime and Qiskit Aer. Amazon Braket IQM `measure_ff`/`cc_prx` serialization, real SDK `Program` construction, dry-run checks, and mocked submission are tested, but no AWS account or real QPU task was used. Device availability, published dynamic groups, credentials, billing, and hardware results remain unverified; persistent-layout/ancilla routing and MPS, TN, distributed, or differentiable execution remain unsupported. |
| Extension SDK | `experimental` | Compatibility is not guaranteed before stabilization. |

These statements are support boundaries, not a development backlog. A
capability is promoted only when all evidence required by its target level
passes `python tools/check_capability_maturity.py`.
