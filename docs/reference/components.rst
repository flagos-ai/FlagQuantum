Component library
=================

The native library joins domain-owned operations, typed register interfaces,
examples and resource models. Compose supported operations through
``circuit.append(op)``; callers do not construct a parallel upstream program.
Start with :doc:`../concepts/REGISTER_PROGRAMS` for the fundamentals, or
:doc:`registers/index` for concise arithmetic and finite-field references.

The complete catalog below is produced from the existing explicit notebook
registry. The documentation build workflow publishes the authored notebooks
before Sphinx renders the site. It preserves their bytes and stored outputs;
rendering does not execute code cells. See
:doc:`../development/DOCUMENTATION_BUILD_WORKFLOW` for those existing commands.

Each example owns its supported parameters, optional dependencies and evidence.
Measured primitive inventories and analytical estimates remain distinct.
Source limitations and unavailable physical bodies stay visible on their
respective pages. This library entry does not promote them to implementation or
hardware acceptance.
