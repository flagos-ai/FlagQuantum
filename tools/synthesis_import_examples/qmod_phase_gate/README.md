# Qmod phase gate

Inspect amplitudes as well as probabilities for a constant phase gate.

Profile: **Qmod import tutorial**.

Run from the repository root.

```sh
python -m tools.synthesis_import_examples.qmod_phase_gate.main
```

[main.py](main.py) retains this tutorial's existing preparation, computation,
result checks and supported syntax. Read its module description for limits.
